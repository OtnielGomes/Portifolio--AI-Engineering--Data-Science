# Customer Segmentation with Clustering 📊

[![scikit-learn](https://img.shields.io/badge/scikit--learn-clustering-F7931E?style=flat-square&logo=scikit-learn&logoColor=white)](https://scikit-learn.org/)

> [!NOTE]
> This project is in progress. The repository and full analysis are not published yet.

**Problem:** Customer segmentation helps businesses tailor products and retention strategies — this project applies unsupervised learning to discover natural groupings in customer data.

**Solution:** A **CRISP-DM** workflow with EDA, feature scaling, and clustering algorithms (K-Means and hierarchical clustering), evaluated with silhouette score.

**Result:** *In progress.*
